# GPTHealthTracker

Prywatna, offline-first aplikacja do wieloletniego monitorowania snu, regeneracji, samopoczucia,
stylu życia, pomiarów ciała i wyników badań laboratoryjnych — z eksportem danych do analizy
przez zewnętrznego asystenta AI.

**To nie jest aplikacja medyczna.** Nie diagnozuje, nie ocenia i nie generuje zaleceń zdrowotnych.
Przechowuje dane, pokazuje trendy i odchylenia oraz przygotowuje zestawienia do rozmowy z lekarzem
lub do dalszej analizy.
